# API endpoints

Generated by `php yii docs/api` from `api/config/routes.php` and the actions' permission checks -
do not edit by hand (`ApiDocTest` fails when this page is stale). Shapes, rules and examples:
[api-contract.md](api-contract.md); who may do what: [access-control.md](access-control.md); changes
from the prototype and per phase: [API_CHANGES.md](API_CHANGES.md).

All paths are under `http://127.0.0.1:8080`. **token**: `Authorization: Bearer <JWT>` from
`POST /v1/auth/login`; out-of-scope records answer 404, a missing permission 403. **public**: no token
(rate-limited where it matters). **API key**: `X-Api-Key` (the sensor simulator).
